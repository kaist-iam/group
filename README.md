# KAIST IAM Group Website

Website: https://kaist-iam.github.io/group/

## How to add a news post

1. Make a new folder in `posts_news/` (e.g. `posts_news/post45/`).
2. Add an `index_post45.qmd` file and images in that folder.
3. Commit to the `main-homepage` branch (or open a pull request to it).

You do not need to render. GitHub Actions renders the site and updates the website automatically (it takes a few minutes).
You can check the progress in the **Actions** tab.
